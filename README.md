# 📌 Overview

This repository contains my practical implementations, experiments, and learning journey in **Generative AI Engineering using LangChain**.

The main goal of this repository is to deeply understand how modern AI systems are built using:

- Large Language Models (LLMs)
- Prompt Engineering
- Retrieval-Augmented Generation (RAG)
- AI Agents
- Vector Databases
- Memory Systems
- LangChain Pipelines
- LLMOps Concepts

Rather than only learning theory, this repository focuses on **building real-world GenAI applications** and understanding how production-level AI systems work internally.
